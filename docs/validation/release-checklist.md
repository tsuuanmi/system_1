# Release checklist

Checks on live accounts and real clients, which fixtures cannot prove
([production-ready exit criteria](../requirements/release-scope.md#production-ready-exit-criteria)).
Record the result of each check for a release. **A skipped item blocks the release.** A check marked
*only with … on* applies only when the release's composition turns that row on
([off by default](../operations/runbooks.md#turn-an-off-row-back-on);
[rows the pilot turns on](../requirements/release-scope.md#rows-the-pilot-turns-on)).

The last column gives the state of each check now. Past evidence is in Git's history.
